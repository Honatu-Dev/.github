## About Honatu

Honatu is a Mexican project based in Querétaro focused on making hydroponics more accessible at home through modular systems, hands-on workshops, and easy-to-use digital tools.

This organization develops solutions that connect technology, urban agriculture, and education—from web platforms and APIs to operational tools that support the growth of our projects.

## What We Do

- **Residential hydroponics**: We design modular solutions for growing fresh food at home.
- **Education and workshops**: We create practical experiences for learning about horticulture and hydroponics.
- **Digital commerce**: We build product and service catalogs with streamlined purchasing experiences.
- **Software development**: We implement web applications, APIs, and internal tools to improve operations.
- **Sustainable innovation**: We explore ways to make urban agriculture more accessible, efficient, and practical.

## Featured Project

### Honatu Hidroponia

A full-stack platform for managing residential hydroponics products, services, and workshops.

It includes:

- Catalog of modular systems and products.
- Workshop reservation engine.
- Customer service request portal.
- Administrative dashboard.
- REST API documented with OpenAPI 3.0.
- JWT-based authentication and role-based access control.
